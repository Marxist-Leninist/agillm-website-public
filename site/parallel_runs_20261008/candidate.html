Binary 4B is Scott's 4,295M-parameter transformer whose weights are single bits (+1 or −1 times one scale per row), trained natively in binary on one RTX 2060. This checkpoint is early (see the checkpoint line for its step, tokens seen and validation loss), so expect English-looking word salad, not answers. It continues text; it is not a chat model.
It runs on GETH's CPU from a 0.56 GB one-bit export. AR decodes one token at a time on net 0 with a KV cache (checked against the full recompute at every load). NAT fills a masked block in 1–4 passes. Diffusion fills 16-token blocks in 4, 8 or 16 passes, each pass on the DiffusionBlocks net that owns the block's current mask ratio; its first run unpacks two more nets (a few seconds). No SAT. One request at a time; no request falls back to another model.
